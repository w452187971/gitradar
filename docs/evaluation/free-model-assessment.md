# 免费开放权重模型阶段评估

结论：免费公开 Actions CPU 能运行固定模型，**当前方案仍未满足可靠自动中文解读，V4 内容验收未通过**。不启用模型自动发布，不使用付费 AI API，不把开发案例或程序绑定原文当成未见准确率。

以下均为同六项已见开发案例的单次实测，不是性能基准或盲评。量化规格、提示步骤和 runner 个体存在差异，不能把差异单独归因为模型参数数量。RSS 仅为 server 进程峰值，不是整机峰值。

| 资产与方法 | 墙钟 | server RSS | 实际结论 |
| --- | ---: | ---: | --- |
| 4B Q5 单步 | 171.215 秒 | 约4.09 GiB | 40个非空字段：支持15、错误11、不足14；仍错归第三方和依赖入口。 |
| 4B Q5 两步 | 593.480 秒 | 约3.78 GiB | 48槽位支持6、错误4、不足5、未知33；仅两个raw有效，分别全未知与英文用途，没有完整可用中文介绍。 |
| 14B Q4 单步 | 749.187 秒 | 约14.46 GiB | 五个有来源项目均超过单项120秒，仅无来源控制完成；40槽位不可评分、8个控制null，不能评价语义。 |
| 8B Q4 单步 | 474.099 秒 | 约9.14 GiB | 六项完整返回，无超时；4/6 raw有效。34个非空字段：支持20、错误5、不足9，另14个真实null；语义未达标。 |

原始失败与独立 AI 审查全部保留：[4B单步](model-third-review.md)、[4B两步](model-fourth-review.md)、[14B](model-fifth-14b-review.md)、[8B](model-sixth-8b-review.md)。更早1.7B两轮也保留原档：第一轮请求schema适配错误已查明，第二轮修复后仍未满足内容要求，不能混作同协议质量基准。

8B确有局部改进：TranslucentTB的八个字段有直接依据，未再为AdGuard和资料仓库拼接获取地址。但Transformers仍把Python版本当平台、PyTorch页面当主项目入口；英语资料仓库仍混入第三方App的平台、形态和设备前提；fd仍无依据输出免费和无特殊要求。有些错误能通过schema、URL字面存在和ref绑定检查，生产隔离必须保留。

每维最多五个有来源独立项目，均不足30；泛化准确率、真人可理解率及未来发现效果仍未验证。六项开发案例上的模型选型和提示调试到此停止，新40项盲样与40个困难反例仍封存，尚未消耗。

下一阶段先验证[生产输入构建](production-input-next-step.md)：程序约束仓库自述、本项目安装、依赖与第三方的来源角色，保存完整条件和失败原因；模型只表达有证断言，结构化URL/许可按原来源绑定。该方案尚未实施，不自动产生ProjectFacts或覆盖curation，须先冻结真实响应到输入的回放，再验证中文语义与完整条件。

工程侧337项Python、75项Node测试通过，三次真实开发分支采集及自动提交通过；旧历史保护有逐点证据。另有[导航计数误撤](freetube-context-change-analysis.md)尚待安全修正，及[Pages闭环审计](pages-publication-audit.md)需在正式更新中明确验证。真人读者、连续14天与末项48小时效果观察尚未完成；正式站仍是V3.3。
