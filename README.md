# GitRadar V2

在 GitHub 仓库 `w452187971/gitradar` 上传本包的文件，保留 `.github/workflows/update.yml` 路径。

到 Settings → Actions → General → Workflow permissions 选择 Read and write permissions。

到 Actions → Update GitRadar data → Run workflow 手动运行一次。此后每天计划自动采集（GitHub 定时任务可能延迟）。

首次采集无法计算 24 小时或 7 天增长；至少需要相隔一天、七天的历史快照。候选项目来自有限搜索，不代表全站排行。无需提供密码或个人令牌。
